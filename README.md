# Angular Gaming Platform 🎮

An interactive **gaming platform built with Angular** where users can log in and play classic games with a modular, scalable architecture.

## Features

* **Games Available:**

  * Snake & Ladder 🐍
  * Tic Tac Toe ❌⭕
  * Stone Paper Scissor ✊✋✌️
  * **Pac-Man** 👾 (coming soon!)

* **Interactive UI:** Engaging, user-friendly interface.

* **Modular Architecture:** Easily add new games using Angular’s module system.
